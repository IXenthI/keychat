Twitch chat for your stream — overlay and OBS dock, with all your emotes.

No accounts. No API keys. No server. Pick your options, copy one URL, done.

Every emote, everywhere

7TV, BetterTTV and FrankerFaceZ — global and channel sets, zero-width stacking, emoji, and Twitch's own emotes and badges.

⚡

Live via 7TV EventAPI

Add an emote on 7tv.app and it shows up in chat instantly. Name paints and 7TV badges render in real time.

🎉

Events & highlights

Subs, gift bombs, raids and announcements as styled lines. First-time chatters, channel-point highlights and @mentions get tinted rows.

🖥️

Overlay or dock

Transparent for on-stream browser sources — or pick a dark background and use it as an OBS custom chat dock that doesn't blind you.

🛡️

Mod-friendly

Word filters, user block list, bot hiding, timestamps, clickable links and pronouns. Deleted messages and bans reflect live.

📦

Nothing to install

A static page you can use right here, self-host, or run from a folder. No login, no tokens, no tracking, no server to die.
